## Global contract

The authoritative flow is scenario + conditions -> deterministic Python flight state -> signed Gz ramps -> original CGEM -> one shared playback timeline -> Three.js views, instruments, lessons, MP4. Advanced catalog maneuvers remain trace lessons; no aircraft motion is inferred from their G trace.

World axes NED; body axes forward/right/down; quaternion xyzw rotates body to NED. Rendering uses east/up/south = [east, -down, -north]. SI internally. Fixed integration step 0.01 s, max 120 s. States always start at t=0 and include the final sample. Every frame contains t_s, position_m[3], velocity_mps[3], quaternion[4], ias_kts, tas_kts, altitude_ft, vertical_speed_fpm, heading_deg, pitch_deg, roll_deg, alpha_deg, gz, phase, controls {aileron_deg,elevator_deg,rudder_deg,throttle,rpm}, forces_n {lift,drag,thrust,weight}. Flight orientation is quaternion authoritative; display Euler values do not drive motion.

POST /simulate-flight request: {scenario: 'coordinated_turn'|'loop'|'aileron_roll'|'immelmann'|'split_s'|'cuban_eight', entry_ias_kts: number|null (null uses scenario default), altitude_ft: number=6000, loading:'solo'|'dual'='solo', intensity_g:number=4, pilot: existing PilotConfigRequest}. New response: {scenario, duration_s, status:'complete'|'stopped', frames:FlightFrame[], phases:[{name,start_s,end_s,description}], events:[{time_s,kind,message}], aircraft:{name,mass_kg,g_limit,vne_kias,va_kias}, provenance:{model_version,flight_model,source_urls:string[],assumptions:string[],parameter_sha256,trace_sha256}, physiology:{status:'available'|'unavailable',reason:string|null,binary_sha256:string|null,result: existing CGEMRunResponse|null}}. Additional response fields must be coordinated with root before changing frontend interfaces. Existing routes unchanged. Frontend model source, loading, aircraft-envelope limits, and CGEM limits must remain visible and distinct.
