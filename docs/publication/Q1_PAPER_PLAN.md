## Target venue

- **Primary**: *Aerospace Medicine and Human Performance* (AMHP).
- **Fallback ladder**: Frontiers in Physiology → Computers in Biology and Medicine → npj Microgravity.
- Submission via `amhp-submit` skill.

## Why this paper is defensible without our own centrifuge subjects

The paper does **not** claim novel physiology. It claims a validated computational framework that:

1. Reproduces a validated FAA model (CGEM) at ~10⁵× the speed.
2. Quantifies prediction uncertainty with split-conformal intervals (distribution-free, calibrated).
3. Detects when inputs leave CGEM's published validation envelope.
4. Identifies which inputs drive G-LOC risk most via global sensitivity analysis.

Each of these is a methodological contribution that stands on the FAA's existing validation work. The synthetic-only validation strategy is **declared explicitly in the Methods and Discussion**, with paper 2 (external re-analysis of published centrifuge data) and paper 3 (own-centrifuge validation) named as the empirical follow-ups.

## IMRaD outline

### Title

*An ML-augmented framework for accelerated G-LOC prediction: surrogate emulation, out-of-distribution detection, and conformal uncertainty quantification of the CAMI G-Effects Model*

### Abstract (250 words, structured)

- Background: CGEM validity envelope, computational cost, no calibrated UQ.
- Methods: synthetic dataset (~11.6 k rows), per-target XGBoost emulator, Mahalanobis OOD, Mondrian conformal CIs, SALib Sobol indices.
- Results: emulator R² ≥ 0.95 across targets; 95 % conformal coverage within ±2 %; OOD AUROC ≥ 0.85 on held-out maneuver families; ~10⁵× speedup.
- Conclusion: a fast, calibrated, OOD-aware extension that preserves the FAA validation chain and is ready for downstream use (real-time advisory, parametric mission planning, future centrifuge studies).

### 1. Introduction

- Aeromedical context: G-LOC risk in fighter, aerobatic, and high-performance flight.
- The FAA CGEM model: history, validation provenance, current usage.
- The gaps:
  - Computational cost (~seconds per scenario) limits parametric exploration.
  - No published surrogate or fast emulator.
  - No calibrated uncertainty quantification beyond binary event prediction.
  - No OOD detector — users can run the model with inputs outside the published validation envelope and get a number with no warning.
- This paper's contribution: an additive ML extension layer that addresses the above without altering the validated Fortran core.
- Structure of the paper.

### 2. Methods

- **The CGEM model**: a one-paragraph summary citing the FAA technical report (Copeland et al.); explicit statement that the Fortran binary and `.f` source are not modified.
- **Synthetic dataset**:
  - Cross-product input grid: 72 maneuvers × 6 `who_profile` × 3 G-tolerance multipliers × 3 dehydration tiers × 3 countermeasure levels.
  - ~11,664 rows, generated by `cgem_ext.data.generate_dataset` with deterministic seeding.
  - Schema documented in `docs/data/datasheet.md`.
  - Reproducibility: dataset hash + binary SHA published with the paper.
- **Train / val / test splits**:
  - 70 / 15 / 15 stratified by maneuver category.
  - Leave-one-group-out folds for OOD-style validation (e.g., train on military ACM, hold out extreme post-stall).
- **Surrogate emulator**:
  - Per-target XGBoost regressors with monotonicity constraints where physiologically required.
  - Hyperparameter search: Optuna with stratified k-fold CV.
  - Conformal prediction: Mondrian split-conformal stratified by maneuver category, target nominal coverage 95 %.
  - Calibration diagnostics: reliability diagrams, expected calibration error (ECE).
  - Interpretability: SHAP TreeExplainer values per prediction.
  - Censored outputs (no event during maneuver): two-stage classifier-then-regressor.
- **Out-of-distribution detection**:
  - Feature space: G_peak, |dG/dt|_max, G-onset duration, who_profile (one-hot), countermeasures (ordinal), hydration, G-tolerance multiplier.
  - `MinCovDet` robust covariance + χ²(df, 0.95) threshold.
  - Comparison baseline: `IsolationForest`.
  - Validation: leave-one-group-out AUROC.
- **Sensitivity analysis**:
  - SALib `saltelli.sample` + `sobol.analyze` driven by the emulator (~10⁴ samples in seconds).
  - First-order, total-order, and second-order indices with bootstrap CIs.
  - Morris elementary effects for cheap screening.
- **Validation protocol**: pre-registered on OSF before any test-set evaluation. Pre-registration locks: train/val/test splits, success thresholds (R² ≥ 0.95, conformal coverage within ±2 %, OOD AUROC ≥ 0.85), and the failure-handling protocol.

  - Wall-clock per evaluation: Fortran subprocess (~3 s) vs emulator (~30 µs) on a single CPU core.

### 4. Discussion

- Aeromedical implications:
  - Parametric what-if analyses for mission planning.
  - Real-time advisory integration in cockpit/flight-surgeon workflows.
  - Personalized G-LOC risk via per-pilot config tuning.
- Comparison to literature:
  - Prior CGEM applications (FAA technical reports, ASEM publications).
  - Other physiological surrogates (cite recent Frontiers/IEEE TBME SciML work).
- Limitations:
  - **Synthetic-only validation**: emulator and OOD validated against CGEM as ground truth. External validation against published centrifuge data is the explicit subject of paper 2 (in preparation). Validation against own centrifuge subjects is paper 3 (in preparation).
  - No individualized physiology beyond CGEM's six `who_profile` presets — Bayesian per-pilot calibration is paper-3 scope.
  - No HRV / wearable integration in this layer (Docs/Manual.md tracks future HRV work).
  - The OOD detector is calibrated against CGEM's *training* envelope, not against physiologically attainable inputs more broadly — abstention is conservative by design.
- Reproducibility:
  - Open code (this repository, MIT-licensed).
  - Open synthetic dataset (Zenodo DOI).
  - Docker image on GHCR with frozen artifact versions.
  - OSF pre-registration link.
- Future work:
  - Paper 2 outline (published-data re-analysis).
  - Paper 3 outline (own-centrifuge validation).
  - Coupled-mode CGEM ↔ Pulse (deferred work item in pulse-sim v2.2.0).

### 5. Conclusion

A short paragraph reiterating: validated FAA model preserved; ML extension provides emulator + OOD + sensitivity + conformal CI; framework ready for downstream aeromedical research without claiming novel physiology.
